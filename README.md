<p>Wolfnix verwendet keine Analytics-Dienste, keine Werbenetzwerke und kein Tracking. Dein Nutzungsverhalten wird nicht erfasst.</p>

<p>Alle gespeicherten Daten (z.B. Benutzername) befinden sich ausschließlich auf deinem Gerät und können jederzeit durch Deinstallation der App vollständig gelöscht werden.</p>
